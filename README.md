🌟 Estrelas do Amanhã
Sistema de formulário de matrícula desenvolvido para facilitar o processo de inscrição de alunos de forma simples, rápida e organizada.

📋 Sobre o Projeto
O Estrelas do Amanhã é uma aplicação web criada para digitalizar o processo de matrícula escolar, permitindo que os responsáveis preencham e enviem informações dos alunos através de um formulário intuitivo.

Este projeto foi desenvolvido com foco em:

Interface amigável
Organização dos dados cadastrados
Melhor experiência para pais e encarregados de educação


🛠️ Tecnologias Utilizadas
HTML5
CSS3
Git
GitHub Pages
📱 Funcionalidades
✅ Cadastro de alunos

✅ Coleta de informações pessoais

✅ Interface moderna 

✅ Validação de campos do formulário
